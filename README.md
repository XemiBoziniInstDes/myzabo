# Myzabo: Virtual Art Gallery & Cultural Hub (2009)

An interactive, multimedia web platform designed to host curated online art exhibitions, foster community discussion, and provide educational resources.

### 🏛️ Project Background
This platform was developed as an independent freelance project, conceptualized and executed entirely from the ground up to bridge the gap between digital art curation and online communities.

* **Type:** Independent Freelance Project
* **My Roles:** Instructional Designer, Curator, Copywriter, Content Strategist

### 🌐 Key Features
* **Virtual Exhibitions:** Showcases curated artworks by various artists inside an immersive digital environment.
* **Community & Learning:** Features integrated discussion forums, educational applications, and a dedicated bibliography section.

### 🎯 My Contribution (Full-Cycle Development)
* **Instructional Design & Curation:** Conceptualized the platform's vision, curated the featured artists, and structured the educational modules and bibliographic data.
* **Creative & Copywriting:** Designed the interactive scenarios, mapped out the complete user journey (storyboards), and authored all textual content and copywriting.

### ⚙️ Technical Note & Emulation
Originally built in Adobe Flash (SWF format). It is preserved and rendered here using the Ruffle emulator to ensure modern web compatibility.
